# 第七部分：7 个已知坑（都踩过）

1. **模板行的 `w:cantSplit` 会静默裁切内容**：文献综述超过一页时，Word 直接丢弃超出部分，页面上毫无异常。必须确保 `allow_row_split()` 生效，并靠渲染复核确认。
2. **表格几何**：模板表宽 9,204 twips；A4 版心 = 11906 − 1418 − 1276 = 9,212 twips。页边距必须写死 **上 2.54 / 下 2.54 / 左 2.50 / 右 2.25 cm**，否则表格左右溢出版心。
3. **不要重复 `tblW` / `tblLayout`**：模板已有 `<w:tblW>` 与 `<w:tblLayout w:type="fixed">`，再追加一个会让 Word 按内容重排列宽，整张表"长得和模板不一样"。
