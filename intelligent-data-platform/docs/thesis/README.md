## 2. 推荐阅读顺序

1. `论文写作_规范操作手册.md` —— 先知道怎么写、什么不能写
2. `REPORT_OUTLINE.md` —— 知道写什么
3. `REAL_DATA_FACTS.md` —— 知道数字从哪来（**写作时唯一出口**）
4. `EVIDENCE_MATRIX.md` —— 知道哪个主张靠哪条证据
5. `REPORT_DRAFT.md` —— 正文本身

答辩前另读：`答辩材料/README.md` → `开题答辩_准备包.md`（或论文答辩版）→ `项目技术讲解_十二讲.md`。

## 3. 两类文档，不要混

| 类别 | 例子 | 数字规则 |
| --- | --- | --- |
| **前瞻性文档**（给老师看） | 论文正文、开题报告、任务书、PPT、答辩稿 | 只能写"现在成立的事实"，且必须与 `REAL_DATA_FACTS.md` 一致 |
| **历史记录文档**（给自己/审查看） | `docs/sprint/*`、`DEVELOPMENT_LOG.md`、`DECISIONS.md`、旧版验收报告 | **不改数字**，只在文首标注"历史记录：本文档记录合成数据阶段结果" |

判断方法：**这份文件会不会被老师看到？** 会 → 前瞻性；不会 → 历史记录。
