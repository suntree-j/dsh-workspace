## 5. 常见坑（都是踩过的，别再踩）

1. **模板行 `w:cantSplit`**：不删就会把超一页的内容静默丢弃，页面上看不出异常。生成后必须 `allow_row_split()`。
2. **表格几何**：模板表宽 9,204 twips；A4 版心 = 11906 − 1418 − 1276 = 9,212 twips。页边距必须写死 **上2.54 / 下2.54 / 左2.50 / 右2.25 cm**，否则表格左右溢出版心。
3. **不要重复 `tblW` / `tblLayout`**：模板已有 `<w:tblW>` 与 `<w:tblLayout w:type="fixed">`，追加第二个会让 Word 按内容重排列宽，整张表和模板"长得不一样"。
4. **PowerShell 传中文**：多行 Python 一律写成 `.py` 文件再执行；用 `-Command` 拼含中文弯引号 `“ ”` 的字符串会被当成分隔符，把句子吞掉。
5. **PowerShell 5.1 读 .ps1 用 GBK**：脚本里不要写中文路径，用 ASCII 路径，最后再挪到中文目录。
6. **Word/PowerPoint COM 残留进程**：导出会打开旧副本，先 `Stop-Process` 再导出，并检查导出的 PNG 时间戳。
7. **改了 docx 的名字**：交付目录用 `02_附件1_任务书.docx` / `03_附件2_开题报告.docx`，不要另存新名字。
